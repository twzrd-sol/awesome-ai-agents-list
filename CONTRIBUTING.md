# Contributing

Thanks for your interest in contributing to this list!

## Guidelines

- **Search before adding** — Make sure the tool/framework isn't already listed.
- **One item per PR** — Keep pull requests focused on a single addition or change.
- **Follow the format** — Use the existing format: `- [Name](URL) — Description.`
- **Write a clear description** — Keep descriptions concise (one sentence) and focus on what makes the tool unique.
- **Alphabetical order** — Add entries in alphabetical order within their category.
- **No duplicates** — If a tool fits multiple categories, list it in the most relevant one.
- **Working links only** — Ensure all URLs are valid and point to active projects.
- **Open source preferred** — Open source projects are preferred, but notable commercial tools are accepted.

## What belongs here

- AI agent frameworks and libraries
- Tools for building, deploying, and monitoring AI agents
- Multi-agent orchestration platforms
- Agent safety and guardrails tools
- Benchmarks and evaluation frameworks
- Learning resources

## What doesn't belong

- General LLM wrappers without agent capabilities
- Prompt engineering tools (unless agent-focused)
- Products with no public documentation

## How to submit

1. Fork this repository
2. Add your entry to the appropriate section
3. Submit a pull request with a clear description of what you're adding

Thank you for helping build this resource!
